---
description: Отслеживание состояния проекта между сессиями
alwaysApply: true
---

При работе над проектом:
1. Перед началом — читай JOURNAL.md чтобы понять текущий статус
2. После завершения сессии — обновляй JOURNAL.md и TODO.md
3. Если проект уже существует — проверяй что файлы не повреждены (нет HTML-сущностей &lt; &gt;)
4. При создании новых файлов через PowerShell используй @' ... '@ для избежания экранирования
