ПЕРЕД любым редактированием файла:
1. Сначала прочитай файл полностью через read_file
2. Убедись что понимаешь контекст и текущее состояние кода
3. Только потом делай multi_edit с точными old_string и new_string
4. Если файл большой (>100 строк) — используй read_file_range для нужного участка
