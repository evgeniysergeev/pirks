При поиске в файлах:
1. Для поиска по содержимому используй grep_search с regex паттерном
2. Для поиска файлов по имени используй file_glob_search
3. Если нужно найти конкретный код — используй codebase семантический поиск
4. Всегда ограничивай поиск нужной директорией если возможно (не ищи во всём проекте)
5. При большом количестве результатов — уточняй паттерн
