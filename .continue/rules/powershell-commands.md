---
description: Правильный запуск команд в PowerShell на Windows
alwaysApply: true
---

При запуске PowerShell команд:
1. Всегда используй `;` вместо `&&` для разделения команд (PowerShell не поддерживает &&)
2. Для смены директории используй `Set-Location <path>` или `cd <path>; команда`
3. Для here-strings с кодом используй @' ... '@ (single quotes) чтобы избежать экранирования
4. Всегда проверяй результат команды — если есть ошибка, читай её полностью перед повторной попыткой
