description: Систематическое решение ошибок компиляции и линковки
alwaysApply: true
---

При ошибках компиляции/линковки:
1. Читай ПЕРВУЮ ошибку полностью — часто она указывает на корневую причину
2. Не игнорируй warnings — они могут стать errors при изменении флагов
3. При ошибке линковки (undefined reference) проверяй:
   - Добавлен ли .cpp файл в CMakeLists.txt
   - Правильно ли подключены библиотеки
   - Есть ли #define для header-only библиотек (STB_IMAGE_IMPLEMENTATION)
4. После исправления — пересобирай весь проект, а не только один файл
